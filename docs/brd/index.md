# 业务需求文档

## 咨询服务方

像我现在面临的一个最主要的困难，就是说如何去收集和整理来自一线的信息，然后把它们汇总成一个框架

目前主要是采取日日志简介的信息架构。日志就是忠实的根据时间和信息先后顺序去记录所有完整的信息，尽可能把散乱的信息给收集到一个业务系统里面。简介呢，就是从这里面去提取关键信息，然后把它们放到正式的看板里

然后再整理成简介的这个过程之中，最大的困难是，AI 会乱编信息架构，人类理解不了，而人类去制定框架的话又不全面，有没有办法完整地能够让。信息能够充分地呃利用起来，然后并且嗯，还需要不断地和人沟通和确认，达成共识

因此，它的核心难点其实是在于信息整理和提炼的难度很大

## 客户

对于客户的话，客户最大的几个顾虑，第一个顾虑首先就是，我花出去的钱到底能干什么？有没有白花？

然后客户可能会对咨询公司有不信任，就是说，比如说价格是不是透明等等

然后客户侧可能有什么问题，我觉得我们可能还需要继续去探究一下感觉这个问题还想得不是很明白
