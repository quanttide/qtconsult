# 量潮咨询

量潮咨询是咨询服务的交付作业台：顾问在上面把一线信息整理成共识，把每个决策留成证据。

## 定位

量潮咨询面向咨询服务的交付过程。顾问最吃力的环节是把散乱的一线信息收集起来、整理成框架——先忠实记录，再提炼进正式看板，期间要不断与人沟通确认才能达成共识，产品为这一段工作而建。

它把咨询方法论固化为四阶段作业流：需求澄清、调研分析、决策方案、执行跟踪。每张卡片承载一个作业事实：客户确认了什么、调研发现指向哪里、方案倾向由谁决定、任务推进到哪一步。方法论落在流程里，每一步都留下痕迹。

客户掏钱时最关心三件事：花得值不值、价格透不透明、过程信不信得过。确认状态、客户倾向、沟通备注与决策链把交付过程沉淀为可查的记录。这些证据目前只在顾问一侧，我们希望把它们开放给客户；进一步地，信息结构与展示方式做成可调整的积木，让甲乙双方共同维护，这是产品文档写下的核心命题。

当前产品服务于量潮自己的顾问团队，客户尚无自己的入口，处于内部使用与验证阶段。

## 用户旅程

1. 为客户开通一个工作区，放入客户资料与项目数据，形成这个客户的作业起点。
2. 打开看板，自动落到该项目；现场没有网络也能继续记录，恢复后同步。
3. 需求澄清：逐条记录客户「要什么」与「现状是什么」，当面核对后标记已确认或待确认。
4. 调研分析：沉淀调研发现，按领域自动归组，把发现串成因果与依赖的脉络。
5. 决策方案：多方案并排对比，标出客户倾向，记下每次客户沟通的关键话。
6. 执行跟踪：拆成任务、落到责任人，推进进度与阻塞直到完成。
7. 在顶栏切换工作区，多个客户项目并行互不干扰。
8. 每一步改动即时保存，事实确认、方案取舍与执行过程沉淀在同一处。

旅程之外，产品文档已写下三件尚未兑现的事：客户本人的自助确认入口、历史报告的结构化导入、可像积木一样调整的信息结构与展示方式。它们是下一阶段的方向。
