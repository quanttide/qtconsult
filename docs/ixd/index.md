# 交互设计文档

## 咨询服务看板 

1. 页面整体布局

· 单页纵向三段，自上而下依次为：事实层、分析层、策略层。
· 每段有固定的标题栏，内容区默认展开，内容较多时各自内部滚动。
· 页面整体可上下滚动，无横向滚动。
· 事实段内部再垂直分为上下两个子区域：业务理想（上）、现实状况（下），两个子区域间有明显的视觉分隔，但仍在同一个“事实层”标题栏下。
· 页面底部保留一条可折叠的“示例线索”横条，跨层示意关联关系。

2. 事实层

2.1 子区域结构

· 上半区（业务理想）：卡片列表，每卡为一条业务期望。
· 下半区（现实状况）：卡片列表，每卡描述一个现状领域。
· 两区域均可内部独立滚动，或随整体页面流式滚动（根据内容长度决定是否使用固定高度容器）。
· 在移动端上，子区域保持上下关系，卡片堆叠展示。

2.2 卡片组件

· 内容：标题（干系人+场景/领域+维度）、简短正文、来源与确认状态。
· 确认交互：卡片右侧有勾选框，供客户点击确认。理想卡片由顾问记录后需客户确认；现实卡片由顾问基于尽调填写，同样需客户确认事实准确性。确认后卡片视觉状态改变。
· 关联能力：每张卡片可被长按或通过拖拽操作（桌面端）/长按菜单（移动端）关联到分析层的某个洞察。亦可被标记为“已对齐”。

3. 分析层

3.1 洞察卡片组件

· 组成：矛盾陈述标题、证据链接标签（点击滚动并高亮对应的事实卡片）、根因文本、影响文本。
· 聚类标签：卡片赋予一个或多个预定义类别，类别可折叠分组显示。
· 新建洞察：页面本层顶部有“新建洞察”按钮，点击弹出内容填写面板，支持手动关联事实层卡片。

3.2 聚类分组

· 分析层内可按聚类标签形成可折叠的分组，默认全部展开。
· 用户可切换显示全部或仅某类别的洞察。

4. 策略层

4.1 策略卡片组件

· 组成：策略名称、关联洞察（链接数量/标题概览）、我们的优势摘要、方案概要、资源与价格范围（含关键假设）。
· 客户选择区：卡片底部包含“倾向本方案”勾选框，以及一个简短文本输入框供客户填写顾虑或条件。
· 咨询团队可新建多个策略卡片，并手动关联洞察。

4.2 交互

· 客户直接在策略卡片的选择区操作，无需跳转。勾选后卡片高亮标示客户倾向。
· 多个策略可同时勾选，支持标注优先级。

5. 跨层联动

· 底部示例线索条默认折叠，点击展开显示一条纵向串联的链条示意：事实→洞察→策略，用垂直线条和节点连接，匹配纵向布局。
· 在桌面端，线索条用垂直连接线视觉引导；在移动端，可调整为步骤指示条样式。

6. 响应式行为

· 整体为单列流式布局，适配不同屏幕宽度。
· 移动端上，卡片维持全宽堆叠，确认勾选框与操作按钮优化为触控友好尺寸。
· 各层内容较长时，页面整体滚动流畅，无嵌套横向滚动。
