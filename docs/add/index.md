# 技术架构文档

这个平台里核心的一个建模机制建模思想呢，就是说要有一个积木块的概念啊，block 的概念。然后这个 block 它既有抽象的形态又有具体的表达形态，比如说可以表格或者以图的形式表达。然后呢，这些信息有一些是可以自定义的，有一些是内置的。比如说像客户的基本信息这些是肯定要内置的。然后像一些具体的信息会可要根据问题去调整

嗯，在做不到这点之前的话，直接手动去维护，就像研发一个新产品一样，不断地去研发新页面。然后，在这个过程之 不断的积累积木块，然后标准化，以方便未来使用。

因为这个方式，因为这个平台是应用层的平台，是一个业务平台，所以说相比之下呢，它的那个灵活程度比较高，我们可以根据自己的需求去自己定制，而不用纠结作为一个领域层服务的稳定性和通用性
