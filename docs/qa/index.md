# 质量保证文档

## 出发点

qtconsult 是咨询项目的信息看板。QA 的核心问题是：**看板上展示的信息，是不是准确反映了客户的真实情况？**

## 用例组织

用例按两个业务实体组织：

| 文件 | 覆盖范围 |
|:-----|:---------|
| `workspace.md` | 进入系统、工作区切换、多租户隔离 |
| `project.md` | OODA 看板展示、卡片操作、数据正确性 |
| `permission.md` | 角色权限、数据可见范围、越权访问防护 |

## 用例格式

每个用例包含：

- **前置条件** — 进入场景前系统处于什么状态
- **操作步骤** — 用户做了什么
- **预期结果** — 用户应该看到什么
