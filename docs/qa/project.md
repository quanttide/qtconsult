# 项目测试用例

## TC-PJ-001 查看 OODA 看板布局

| 项目 | 内容 |
|:-----|:-----|
| 前置条件 | 应用已启动并加载项目看板 |
| 操作步骤 | 看板加载后，观察页面结构 |
| 预期结果 | 1. 页面顶部显示「咨询服务看板」标题<br>2. 横向排列四个栏目：Observe、Orient、Decide、Act<br>3. 各栏标题使用「动词 · OODA阶段」格式（如「调研 · Observe」）<br>4. 各栏宽度比例合适，不出现横向滚动条 |

| 操作步骤 | 查看 Observe 栏 |
| 预期结果 | 1. 栏内分左右两个子区域：「业务理想」（ideal）和「现实状况」（reality）<br>2. 每个子区域的卡片列表正确显示<br>3. 每张卡片显示标题、描述、来源、确认状态<br>4. 理想与现实之间有视觉区分（底色或边框） |

## TC-PJ-006 切换 Observe 卡片确认状态

| 项目 | 内容 |
|:-----|:-----|
| 前置条件 | Observe 栏有未确认卡片 |
| 操作步骤 | 点击卡片的确认按钮 |
| 预期结果 | 1. 卡片状态从「待确认」变成「已确认」<br>2. 再次点击，恢复为「待确认」<br>3. 状态切换反映在卡片视觉上 |
