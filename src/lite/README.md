# qtconsult-lite

量潮咨询的 **AI 办公方案页**：WorkBuddy + 腾讯文档的平台选型结论与分工口径。

- **这里**：AI 办公咨询方案的对外展示（结论、计算与存储单元分工、步骤状态）
- **正本**：咨询档案 quanttide-profile-of-consulting-management 的 `vibe-working/platform-decision`

## 开发

```bash
npm install
npm test        # vitest
npm run lint    # eslint
npm run build   # tsc -b && vite build
```

## 许可

随仓库许可。
