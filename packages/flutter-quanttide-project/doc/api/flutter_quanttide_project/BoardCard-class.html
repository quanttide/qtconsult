BoardCard

BoardCard class

看板卡片。

字段分四组：

  • 标识：id、title、description
  • 分类：category（系统分类）、tags（多维度标签，Map<String, String>）
  • 上下文：date（时间）、assignee（负责人）
  • 扩展：custom（自定义字段，序列化时展开到 JSON 根层级）
